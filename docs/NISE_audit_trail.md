## Annotation Ambiguity Disclosure

The recurring CNBC "Stocks making the biggest moves [midday/premarket/after hours]" template (pairs 006–010 in `candidate_sample_250.json`) is a genuinely difficult annotation boundary: same column format, same outlet, different trading sessions, different tickers, published hours apart. Annotators resolved as SAME based on shared column context. A different annotator might reasonably label DIFFERENT. Disclosed in manuscript (one sentence, Section III-J). Does not invalidate κ = 0.8454 but worth citing in any rebuttal if a reviewer challenges the real-corpus IAA.
